# Governance Mermaid diagrams

Governance does not maintain Access's provider ceremony diagrams. The Base App and Base Org RP
session lifecycles are Governance-owned and each has an active diagram and transition inventory:

- [Base App RP session lifecycle](rp-base-app-session-lifecycle.mmd)
- [Base App RP session transition inventory](rp-base-app-session-transition-inventory.md)
- [Base Org RP session lifecycle](rp-base-org-session-lifecycle.mmd)
- [Base Org RP session transition inventory](rp-base-org-session-transition-inventory.md)

The APP pending registration lifecycle is an accepted Governance-owned axis (design only, not
implemented; owner items decided 2026-11-15 in its ADR amendment):

- [APP pending registration lifecycle (accepted, not implemented)](app-pending-registration-lifecycle.mmd)
- [APP pending registration transition inventory (accepted, not implemented)](app-pending-registration-transition-inventory.md)

The 39 visitor and COM diagrams under `archive/visitor-com-retired/` are historical material. They
remain for provenance and do not describe current Governance behavior.

Governance owns RP state and audit records. For a newly accepted Governance-owned state axis,
establish its owner and transition writer from the current decision and implementation, add a
diagram and transition inventory for that axis, and link them from this page. Keep service-owned
Access ceremony axes in Access documentation.
