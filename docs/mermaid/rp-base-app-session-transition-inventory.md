# Base App RP Session Transition Inventory

Owner: Governance Base App RP cell (`rp_base_app`). The RP session row stores terminal revocation in
`rp_sessions.revoked_at`; `absolute_expires_at` supplies a derived expiry condition. An OP `sid`
binding may also carry a revocation timestamp so later callbacks cannot reopen a logged-out session.

| From              | To                | Public entry / writer                                                                      | Guard and committed effect                                                                                                                                                                                                                                                                                              |
| ----------------- | ----------------- | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| No local session  | Active            | `GET /oidc/callback` → `OidcCallback` → `RpCallbackCommitter`                              | Validate signed browser state and response issuer first; verify the exact two-minute PS256 ID Token with Visa JWKS; consume its JTI once and commit identity binding, `sid` binding, authentication evidence and RP session on the writer before resetting the Rails session and installing only the RP session cookie. |
| Expired (derived) | Active            | Private-page redirect → CSRF-protected `POST /sign` with `prompt=none` → verified callback | The signed pending flow carries the expired local session reference. The callback renews that same session only when its verified subject and OP `sid` binding match. `login_required` returns to ordinary sign entry.                                                                                                  |
| Active            | Revoked           | CSRF-protected `POST /sign/out` → `RpBaseAppSession#revoke_for_sign_out!`                  | Require the current active Base App RP session. Lock the `sid` binding and session, then commit local revocation before clearing cookies or leaving through Jump.                                                                                                                                                       |
| Active            | Revoked           | `POST /oidc/closures` → `OidcOpLogoutTokenVerifier` → `RpCellSessionRevoker`               | Require the fixed Visa PS256 Logout Token and client; one transaction tombstones the `sid`, revokes matching sessions and records the replay receipt before 200.                                                                                                                                                        |
| No local session  | Revoked binding   | `POST /oidc/closures` → `RpCellSessionRevoker`                                             | A verified logout for an unseen `sid` commits a tombstone so a later callback cannot reopen it.                                                                                                                                                                                                                         |
| Active            | Expired (derived) | `absolute_expires_at` check in RP authentication                                           | No write occurs. A session past the timestamp is ineffective without changing `revoked_at`; the expired row remains eligible only for the matching `prompt=none` renewal.                                                                                                                                               |

Revoked sessions and bindings are terminal. A repeated verified event with the same JTI and SID is
acknowledged once; reuse of a JTI for a different SID conflicts. State ownership and route scope
follow the 2026-11-14 Base App RP restoration order and the accepted separated-RP sign-out ADR.
